Cómo lee una dirección

Una esquina es un punto. Una cuadra es un círculo.

«Entre L y M» no es un punto: es una cuadra, y el círculo lo dice, porque el radio es la mitad del tramo. Un hotel o un parque salen de OpenStreetMap. Cada respuesta trae municipio, barrio y la precisión con que se encontró.

Búsqueda inversa

Sin internet

Una máquina, ninguna conexión.

Geocoder se entrega como imagen Docker o en una memoria USB, con su mapa, sus datos y su API dentro. Nada sale a internet. Los datos vienen de OpenStreetMap y se actualizan al reconstruir la base.

Para desarrolladores

Una API REST y una línea de comandos.
